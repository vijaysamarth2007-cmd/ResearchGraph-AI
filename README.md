# 🧠 ResearchGraph AI

ResearchGraph AI is a Streamlit-based research knowledge graph application.

## 📌 Project Description

The application allows users to upload multiple research papers in PDF format and automatically extract important research entities such as:

- 👨‍🔬 Researchers
- 🔬 Research Topics
- 🗃️ Datasets
- ⚙️ Research Methods

The extracted entities are visualized as a combined knowledge graph.

## 🚀 Features

- Upload multiple research papers
- Extract text from PDF files
- Detect research entities
- Create a visual knowledge graph
- Identify relationships between research papers
- Compare shared topics, methods, datasets and researchers
- Display relationship strength between papers

## 🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF
- NetworkX
- Matplotlib
- Regular Expressions
